# 手工上传备用方案（只在不用 git 时看）

网页上传能传普通文件夹，但 **`.github` 和 `.gitignore` 是隐藏项，拖不进去**，
必须在网页上手动新建。下面三段是完整内容，逐段复制即可。

## 新建文件的方法

仓库首页 → **Add file** → **Create new file** → 在文件名框里**直接输入带斜杠的完整路径**
（例如 `.github/workflows/sync.yml`，GitHub 会自动把 `/` 变成目录）→ 粘贴内容 → **Commit changes**。

## `.github/workflows/sync.yml`

> 必需：每天 8:30 跑抓取 + 推送

```yaml
# 每日同步杭州外企设计岗（GitHub Actions + 静态数据，零服务器零运维）。
# 每次跑 sync 做【增量累积】（新增追加、消失标 gone、保留用户状态），
# 再导出 jobs.html，把 data/ commit 回仓库；前端/浏览纯静态读取。
#
# 时间：每天北京时间 08:30。
# GitHub 从 2026-03 起支持 schedule 的 timezone 字段（官方 changelog）。
# ⚠ 一旦指定了 timezone，cron 就按**本地时间**解释，不要再手动换算成 UTC：
#     timezone: "Asia/Shanghai" + cron "30 8 * * *"  = 北京 08:30 ✅
#     timezone: "Asia/Shanghai" + cron "30 0 * * *"  = 北京 00:30 ❌
#   （旧写法是靠 UTC 换算，加了 timezone 后必须改成 8 点，否则会提前 8 小时跑）
#
# 必配 Secrets（Settings → Secrets and variables → Actions）：
#   FEISHU_WEBHOOK_URL   飞书群机器人 webhook（主通道）
#   PUSHPLUS_TOKEN       pushplus token（推个人微信，可选）
#   FEISHU_SECRET        飞书机器人开了"签名校验"才需要（可选）
# 可选 Secrets（配了就自动启用，不配跑规则版）：
#   LLM_API_KEY          OpenAI 兼容接口的 key，用于把英文 JD 压成中文要点
#   LLM_BASE_URL         自建/中转网关地址，默认 https://api.openai.com/v1
#   LLM_MODEL            模型名，默认 gpt-4o-mini
# 可选 Variables：
#   WORKBENCH_URL        你自己的 GitHub Pages 地址，例如 https://<you>.github.io/job-radar/
name: job-radar-sync

on:
  schedule:
    - cron: "30 8 * * *"
      timezone: "Asia/Shanghai"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  sync:
    runs-on: ubuntu-latest
    timeout-minutes: 40
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Run daily fast sync
        run: python3 scripts/sync_plan.py fast

      # 回查达标岗位的详情接口：拿 JD 正文、真实发布日期、职位号
      # 失败不阻塞播报——没有 JD 就退化成"只有标题 + 官网链接"，如实说明
      - name: Enrich JD (detail API)
        continue-on-error: true
        run: python3 scripts/enrich_jd.py --min-match 55 --limit 40

      # 判链接生死：Workday 走详情接口（活岗 200 / 死岗 404），其他走页面启发式
      - name: Verify job links
        continue-on-error: true
        run: python3 scripts/verify_links.py --min-match 55 --limit 40

      - name: Build notify preview
        env:
          WORKBENCH_URL: ${{ vars.WORKBENCH_URL }}
          LLM_API_KEY: ${{ secrets.LLM_API_KEY }}
          LLM_BASE_URL: ${{ secrets.LLM_BASE_URL }}
          LLM_MODEL: ${{ secrets.LLM_MODEL }}
        run: python3 scripts/notify_preview.py

      - name: Send notify (feishu / pushplus / wecom)
        env:
          FEISHU_WEBHOOK_URL: ${{ secrets.FEISHU_WEBHOOK_URL }}
          FEISHU_SECRET: ${{ secrets.FEISHU_SECRET }}
          PUSHPLUS_TOKEN: ${{ secrets.PUSHPLUS_TOKEN }}
          PUSHPLUS_TOPIC: ${{ secrets.PUSHPLUS_TOPIC }}
          WECHAT_WEBHOOK_URL: ${{ secrets.WECHAT_WEBHOOK_URL }}
          WECOM_WEBHOOK_URL: ${{ secrets.WECOM_WEBHOOK_URL }}
          WORKBENCH_URL: ${{ vars.WORKBENCH_URL }}
          LLM_API_KEY: ${{ secrets.LLM_API_KEY }}
          LLM_BASE_URL: ${{ secrets.LLM_BASE_URL }}
          LLM_MODEL: ${{ secrets.LLM_MODEL }}
        # 推送失败不让整个任务红：数据已经抓到了，下次会补推
        continue-on-error: true
        run: python3 scripts/send_notify.py

      - name: Upload daily report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: daily-report
          path: data/reports/*.md
          if-no-files-found: ignore
          retention-days: 30

      - name: Commit data
        run: |
          git config user.name  "job-radar-bot"
          git config user.email "job-radar-bot@users.noreply.github.com"
          git add data/
          if git diff --cached --quiet; then
            echo "无新增/变更岗位，跳过 commit"
          else
            git commit -m "chore(data): sync jobs $(date -u +%F)"
            git push
          fi
```

## `.github/workflows/pages.yml`

> 可选：更新信息台网页

```yaml
# 轻量部署信息台：代码/样式/README 更新时只刷新 GitHub Pages，不跑完整抓取、不发推送。
name: job-radar-pages

on:
  push:
    branches: [main]
    paths:
      - "data/jobs.html"
      - "data/notify_preview.md"
      - "scripts/export_html.py"
      - "job_radar/**"
      - ".github/workflows/pages.yml"
      - "README.md"
  workflow_run:
    workflows: ["job-radar-sync"]
    types: [completed]
  workflow_dispatch: {}

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  deploy:
    if: github.event_name != 'workflow_run' || github.event.workflow_run.conclusion == 'success'
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Export HTML
        run: python3 scripts/export_html.py

      - name: Prepare Pages artifact
        run: |
          mkdir -p public
          cp data/jobs.html public/index.html
          cp data/jobs.html public/jobs.html
          if [ -f data/notify_preview.md ]; then
            cp data/notify_preview.md public/notify_preview.md
          fi

      - uses: actions/upload-pages-artifact@v3
        with:
          path: public

      - uses: actions/deploy-pages@v4
```

## `.github/workflows/slow.yml`

> 可选：每周深度扫描

```yaml
# 慢源补扫：牛客、实习僧、SPA 高校、飞书招聘等浏览器/社区源。
#
# ⚠ 本仓库已定向为「杭州外企 UX/交互/产品设计」：
#   config/sources.csv 里已经没有校招/高校/实习僧/牛客等源，
#   所以这个 slow 任务没有可抓的信源，每天只会空跑 30 分钟。
#   保留文件仅为将来若要接社区源时方便恢复——把下面的 schedule 注释取消即可。
name: job-radar-slow

on:
  # schedule:
  #   - cron: "47 9 * * 3,0"
  #     timezone: "Asia/Shanghai"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  slow:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: |
          python3 -m pip install --quiet -r requirements.txt
          python3 -m playwright install --with-deps chromium

      - name: Run slow sync
        run: python3 scripts/sync_plan.py slow

      - name: Build notify preview
        env:
          WORKBENCH_URL: https://jasmine-liu-min.github.io/job-radar/
        run: python3 scripts/notify_preview.py

      - name: Send new-only notify
        env:
          FEISHU_WEBHOOK_URL: ${{ secrets.FEISHU_WEBHOOK_URL }}
          WECHAT_WEBHOOK_URL: ${{ secrets.WECHAT_WEBHOOK_URL }}
          WECOM_WEBHOOK_URL: ${{ secrets.WECOM_WEBHOOK_URL }}
          WORKBENCH_URL: https://jasmine-liu-min.github.io/job-radar/
        run: python3 scripts/send_notify.py

      - name: Commit data
        run: |
          git config user.name  "job-radar-bot"
          git config user.email "job-radar-bot@users.noreply.github.com"
          git add data/
          if git diff --cached --quiet; then
            echo "无新增/变更岗位，跳过 commit"
          else
            git commit -m "chore(data): slow sync jobs $(date -u +%F)"
            git push
          fi
```
